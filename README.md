# FisherKing

A collection of ComfyUI workflows, reference implementations, and productivity tools for image and video generation.

## ComfyUI Workflow Series

FisherKing workflows focus on practical, reusable implementations with an emphasis on:

- Model-specific reference workflows
- Productivity-oriented workflow design
- Modular and understandable architectures
- Low-VRAM accessibility where practical
- Image and video generation
